# 0008: How agent answers are scored
- **Rules, not an LLM judge:** free, deterministic, and cannot share the answering model's blind spots. Contract facts need the gold value and no competing values (e.g. exactly one of 15/30/45/60 days named); money compares exact `Decimal`s after removing dates and invoice numbers; lists need exactly the right invoice numbers; multi-hop vendor answers must name the gold vendor and no other vendor.
- **Citation precision:** share of cited chunks from a document that holds the answer (contract: gold document AND page; invoice aggregates: any invoice of that vendor in the asked range), over answers that cite something. Not defined for multi-hop.
- **Known limits:** an answer listing two values is marked wrong even if it hedges toward the right one; an answer that happens to contain the right number for the wrong reason is marked right; questions are templated by us, so this is a regression benchmark, not a claim about real-world accuracy.
