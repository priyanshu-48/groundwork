# 0017: Structured contract answers carry verified citations
- **Context:** 9 of 35 contract-lookup answers (m6c) had no citation. All were simple questions ("renews automatically?", "payment terms?") answered in one step from `query_contracts`, which returned facts with no page. The system prompt already told the model to use `search_documents` for one contract's clauses; the small model skipped it about a quarter of the time, so a stronger prompt would only have improved the odds.
- **Decision:** for a lookup of one to three vendors, `query_contracts` finds, per fact, the chunk of that contract that states it (`keyword_search` limited to the contract's document, one fixed phrase per fact) and returns its ref in a `sources` map. Refs go through the usual registration and validation, so the model cannot invent them and the UI chips are unchanged. Longer lists ("which vendors are net-30") return no sources. The prompt and tool description say to cite the given ref.
- **Result (m10):** contract-lookup coverage 26/35 to 35/35 with accuracy 100% and citation precision 100%; invoice and multi-hop accuracy unchanged. On all 25 contracts the cited page equals the ground-truth page for 150 of 150 facts.
- **Alternatives:** forcing a retry when an answer is uncited (an extra model call per question, still model-dependent); storing each fact's page at extraction time (migration, re-extraction and a reload of the live corpus for the same effect); attaching a search result after the fact (can cite a plausible wrong page).
- **Found while tuning:** a phrase built from "written notice days" also matched indemnity and assignment clauses and picked the wrong page for one vendor; a payment-terms phrase tied with the late-fee clause. The page-pin test and a 25-contract check caught both. Phrases now use clause heading words.
- **Limits:** the phrases are tuned on the generated corpus's clause wording; messy real contracts may need re-tuning (the pin test is the guard). Computed answers (invoice totals, multi-hop) still cite no source document.
