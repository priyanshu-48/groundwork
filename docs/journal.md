# Groundwork journal (interview reference)

## Major decisions
| Date | Decision | Alternatives | Why |
|---|---|---|---|
| 2026-10-16 | Job queue = Postgres table with `FOR UPDATE SKIP LOCKED` | SQS, Redis/Celery | No extra infra, transactional with the document insert, portable across AWS/Oracle |
| 2026-10-16 | Hand-written tool-calling agent loop | LangChain, LangGraph | Shows understanding of the mechanics; fewer dependencies; full control of limits and citation validation |
| 2026-10-16 | Host-agnostic deploy (Docker Compose, S3-compatible storage, plain Postgres+pgvector) | AWS-native services (Lambda, Cognito, etc.) | AWS free tier ends; planned move to Oracle free tier must be config-only |
| 2026-10-16 | Strict AWS cost/secret guardrails (budget alarm, no NAT/multi-AZ, SSM, instance roles, gitleaks, user runs all AWS mutations) | Ad-hoc | Avoid leaked keys and surprise bills on a free-tier account |
| 2026-10-16 | No Co-Authored-By trailers in commits | Default attribution | Owner's preference: the repo history is the author's own work |
| 2026-10-16 | RustFS replaces MinIO for local/test S3 | SeaweedFS, LocalStack, pinned old MinIO | MinIO's public images were removed; S3 API is the contract, so the app is unaffected (ADR 0001) |
| 2026-10-16 | M1 auth: argon2 hashing off the event loop, HS256 JWT (sub, org_id, exp) with algorithm whitelist, signup creates org+user, identical 401 for unknown email vs wrong password (dummy-hash verify), app refuses to boot without a 32+ char JWT_SECRET | bcrypt, refresh tokens, invites | argon2 is the current OWASP pick; to_thread keeps the loop responsive; whitelist blocks alg=none; no enumeration; fail-closed secret. org_id only ever comes from the verified token |
| 2026-10-16 | M2: upload does S3 put first, then document+job in one DB transaction; reaper fails jobs already at max_attempts instead of requeueing; PDF checked by magic bytes and read in 1 MB chunks capped at 20 MB; native Postgres enums | DB first then S3; plain requeue in reaper; trust content-type | Deterministic key makes S3 retries harmless and avoids rows pointing at missing files; a poison job that kills workers must not loop forever; content-type is client-controlled; never buffer attacker-sized bodies |
| 2026-10-16 | M3 ingestion: slow work (S3, parse, embed, LLM) first, then one transaction that deletes old chunks and inserts new ones; permanent vs transient errors; invoices stored but flagged (partial unique index); embeddings L2-normalized; page/chunk caps; worker refuses to start with AI_PROVIDER=gemini and no key | Hold a DB transaction across the Gemini calls; retry everything; fail the job on bad totals; silently fall back to fake embeddings | No long transactions or half-written state, so a killed worker leaves 0 duplicates; retrying a corrupt PDF is pointless; flagged rows keep evidence without poisoning aggregates; truncated 768-d Gemini vectors are not unit length; caps bound cost; fake embeddings in a real index would silently ruin retrieval |
| 2026-10-16 | M4: synthetic corpus with gold pages known by construction and verified by re-reading the PDFs; retrieval scored on the right contract AND page; fake-embedder numbers blocked from docs/evals.md; free-tier pacing via min-interval throttles; iterative HNSW scan on every search | Detect gold pages by searching text afterwards; score at document level only; allow fake numbers with a label | Ground truth must be correct before any metric means anything; page-level is what citations need; a harness check must not become a resume number; bulk loads would otherwise hit 429s; a selective org filter can starve a plain HNSW scan of results |
| 2026-10-16 | graphify knowledge graph for repo navigation | Raw grep each session | Cheaper context, persistent architecture map |

## Roadblocks
| Date | Symptom | Root cause | Fix | Lesson |
|---|---|---|---|---|
| 2026-10-16 | `docker compose up` api crashed: `No module named 'app'` in alembic env.py | Alembic CLI doesn't add cwd to sys.path; pytest masked it because rootdir was on the path | `prepend_sys_path = .` in alembic.ini | Test the container path, not just pytest |
| 2026-10-16 | Compose failed binding 5432 | Windows/another service already holds the port | Host port 5433 (container stays 5432) | Keep host ports configurable |
| 2026-10-16 | Testcontainers `ImageNotFound` for minio/minio | Upstream removed the image | Switched to RustFS | Pin and verify images early |
| 2026-10-16 | Test and compose still referenced MinIO-era patterns after M0 fix: new worker test data leaked across tests (duplicate-invoice test saw other tests' rows) | Shared session-scoped DB and an unscoped SELECT in the test | Scope every test query by the test's own org_id | Tests on a shared DB must filter by their own tenant |
| 2026-10-16 | Fake-embedder retrieval test found the right contract but never the right page | The fake hashed every word, so shared stopwords (the, is, in) made all pages look alike | Drop a small stopword list in the fake | A fake that cannot retrieve cannot validate retrieval code; keep fakes just good enough, and never read quality from them |
